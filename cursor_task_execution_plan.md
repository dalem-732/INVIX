Посмотрю, где в боте и на странице подключается Mini App и что сейчас мешает открыть его из Telegram.

Кнопка Mini App в боте открывает страницу каталога внутри Telegram. Сейчас этой кнопки нет: в `.env` стоит `WEBAPP_URL=http://localhost`, а Telegram принимает для Mini App только публичный `https://`.

Бот добавляет кнопку «Открыть каталог», только если адрес начинается с `https://`:

```40:45:bot/bot/main.py
def catalog_markup(user_id: int | None) -> InlineKeyboardMarkup | None:
    rows: list[list[InlineKeyboardButton]] = []
    if settings.webapp_url.startswith("https://"):
        rows.append(
            [InlineKeyboardButton(text="Открыть каталог", web_app=WebAppInfo(url=settings.webapp_url))]
        )
```

Страница каталога подключает скрипт Telegram и при открытии внутри клиента вызывает `ready()` и `expand()`, чтобы Mini App развернулся на весь экран:

```12:18:frontend/app/layout.tsx
      <body>
        <Script src="https://telegram.org/js/telegram-web-app.js" strategy="beforeInteractive" />
        <TelegramBootstrap />
        {children}
```

Телефон не видит `localhost` вашего компьютера. Нужен туннель на порт 80, например:

```bash
cloudflared tunnel --url http://localhost:80
```

Полученный адрес вида `https://….trycloudflare.com` запишите в `.env` в `WEBAPP_URL` и перезапустите бота:

```bash
docker compose up -d --no-deps --force-recreate --scale bot=1 bot
```

Дальше в @invixx_bot отправьте `/start` и нажмите «Открыть каталог». Откроется та же страница «Каталог», что и в браузере, уже внутри Telegram. `PUBLIC_BASE_URL` для этой проверки не нужен: бот и так забирает сообщения сам.
